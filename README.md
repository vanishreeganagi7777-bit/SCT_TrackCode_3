# SCT_TrackCode_3
# 🎓 Exam Prep Quiz

A modern, responsive Quiz Application built using HTML, CSS, and JavaScript. The app provides an interactive quiz experience with a timer, progress tracking, instant feedback, score calculation, dark mode, and local storage support for saving the highest score.

## ✨ Features

- 📚 15 Multiple Choice Questions
- ⏱️ 15-Second Timer for Each Question
- 📊 Progress Bar Tracking
- ✅ Instant Answer Feedback
- 🏆 Score Calculation & Results Screen
- 💾 Best Score Saved Using Local Storage
- 🌙 Dark Mode Toggle
- 🔀 Randomized Questions and Options
- 📱 Fully Responsive Design
- 🎨 Modern UI with Smooth Animations
- 🔊 Audio Feedback for Correct/Incorrect Answers

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Tailwind CSS

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/vanishreeganagi7777-bit/SCT_TrackCode_3.git
```

2. Open the project folder:

```bash
cd SCT_TrackCode_3
```

3. Open `index.html` in your browser.

No installation or dependencies are required.
